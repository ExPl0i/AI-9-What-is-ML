# Что такое машинное обучение. Данные и выборки

Вводное занятие курса «Искусственный интеллект» для 9 класса. Ученики знакомятся с идеей машинного обучения и своими руками готовят данные: генерируют их, перемешивают, делят на выборки и строят простейшие модели-ориентиры.

## Содержимое

| Файл | Описание |
|---|---|
| `Что_такое_машинное_обучение.pptx` | Презентация к занятию (24 слайда) |
| `Данные и выборки.ipynb` | Практическая работа (8 заданий + задания повышенной сложности) |

## Теория (презентация)

1. **Что такое машинное обучение** – два способа получить программу, определение, короткая история, ИИ / машинное обучение / глубокое обучение, три вида обучения, применение.
2. **Данные** – таблица «объект – признак», классификация и регрессия, пять этапов работы, исследовательский анализ.
3. **Выборки** – модель-зубрила, обучающая / валидационная / тестовая выборки, перемешивание, стратификация, утечка данных, модель-ориентир.

## Практическая работа

Ученик пишет с нуля все, что в следующих работах стоит в «готовой ячейке»:

1. Генератор данных «тормозной путь» (регрессия).
2. Перемешивание номеров объектов своими руками.
3. Генератор данных беспилотника: скорость, длина, высота и расстояние до объекта; классы – пешеход, велосипедист, автомобиль.
4. Разведка данных.
5. Разбиение на обучающую и тестовую выборки.
6. Стратифицированное разбиение.
7. Модель-ориентир и модель-зубрила.
8. Ориентир для регрессии (RMSE).

Задания повышенной сложности: кросс-валидация (k-fold), ловушки арифметики с плавающей точкой, устойчивость оценки к зерну разбиения, утечка при нормализации.

**Правило работы:** только встроенный Python и модуль `random` через свой генератор `random.Random(seed)`. Без `numpy`, `pandas`, `sklearn`.

## Как работать

1. Откройте ноутбук в Jupyter или Google Colab.
2. В ячейках с заданиями замените `...` своим кодом (подсказка – в комментарии `# <--`).
3. Сверьте напечатанное значение с тем, что указано после слова «ожидается».

## Требования

Python 3.8+. Для необязательных ячеек сверки и графиков: `scikit-learn`, `matplotlib`.
